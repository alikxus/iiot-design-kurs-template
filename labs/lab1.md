**Тривалість: 2 академічні години · Лекція 1 · Файли: `iiot/sim.py`, `docs/tz.md`**

## Мета
Описати вимоги до IIoT-системи моніторингу насосної станції та реалізувати симулятор агрегату, який буде джерелом даних для всього курсу.

## Частина A. Технічне завдання (≈ 30 хв)
Створіть `docs/tz.md` (1–2 сторінки) за шаблоном із лекції 1: мета, межі системи, 4–6 FR, 4–6 NFR (**кожна вимога вимірювана**), інтерфейси, критерії приймання. Додайте схему архітектури (текстова чи зображення) із шарами edge / сервер.

## Частина B. Симулятор (≈ 1 год 30 хв)
Створіть пакет `iiot/` (файл `iiot/__init__.py` уже є) та модуль `iiot/sim.py` з класом `PumpSimulator`.

### Інтерфейс
```python
PumpSimulator(device_id="pump-01", seed=None, wear_rate=0.0)
.running: bool            # True за замовчуванням
.wear: float              # 0..1
.inject_fault(kind)       # "bearing" -> wear >= 0.7; "clog" -> засмічення; інше -> ValueError
.step(dt=1.0, now=None) -> dict
```

### Формат результату `step()`
```json
{"device_id": "pump-01", "ts": 1760000000.0, "running": true,
 "metrics": {"vibration_mm_s": 1.84, "temperature_c": 55.2, "pressure_bar": 4.19, "current_a": 12.1}}
```
`ts` = `now`, якщо задано, інакше `time.time()`.

### Модель (орієнтир; константи можна підібрати власні, але тести мають проходити)
- Справний агрегат: вібрація ≈ 1,8 мм/с, температура ≈ 55 °C, тиск ≈ 4,2 бар, струм ≈ 12 А, плюс гауссів шум.
- Знос `wear` збільшує вібрацію (≈ +6 мм/с при wear=1), температуру (≈ +25 °C) та струм.
- Засмічення `clog` знижує тиск і підвищує струм.
- Агрегат зупинено (`running=False`): тиск і струм = 0, вібрація ≈ 0, температура повільно спадає до 25 °C.
- Власний генератор `random.Random(seed)` — для відтворюваності.
- `wear` зростає на `wear_rate` за кожен крок і не перевищує 1.
