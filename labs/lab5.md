# Лабораторна 5. Аномалії та залишковий ресурс (RUL)

**Тривалість: 2 академічні години · Лекція 5 · Файл: `iiot/analytics.py`**

## Мета
Реалізувати прості інтерпретовані методи предиктивного обслуговування та застосувати їх до даних вашого симулятора.

## Завдання
У `iiot/analytics.py`:

1. `ewma(values, alpha=0.3) -> list[float]` — експоненційне згладжування; перший елемент = першому значенню.
2. `RollingZ(window=30, min_samples=10)` з методом `update(x) -> float | None`:
   - повертає `None`, поки у вікні менше `min_samples` значень;
   - z-оцінка обчислюється за **попереднім** вікном (поточне значення додається **після** обчислення); стандартне відхилення — популяційне, з нижньою межею `1e-6`.
3. `detect_anomalies(values, window=30, threshold=3.5) -> list[int]` — індекси значень із `|z| > threshold`.
4. `linear_trend(ts, values) -> (slope, intercept)` — МНК, `sxx == 0` → `slope = 0`.
5. `estimate_rul(ts, values, limit) -> float | None`:
   - `0.0`, якщо останнє значення вже `≥ limit`;
   - `None`, якщо нахил `≤ 1e-12`;
   - інакше `max((limit − intercept)/slope − ts[-1], 0)` у тих самих одиницях, що й `ts`.

## Експеримент
Напишіть `run_experiment.py` (або ноутбук):
1. Згенеруйте 600 кроків симулятора з `wear_rate=0.001` (`now = крок`).
2. Побудуйте сирий сигнал вібрації та `ewma`.
3. Знайдіть аномалії; додайте штучні викиди й перевірте, що вони виявляються.
4. Кожні 50 кроків оцініть RUL до межі 4,5 мм/с за останніми 100 точками. Побудуйте графік «оцінка RUL у часі» та порівняйте з фактичним моментом перетину межі.

Зробіть **висновок** (3–5 речень): наскільки точна лінійна оцінка, чому вона відхиляється, що б ви змінили.
